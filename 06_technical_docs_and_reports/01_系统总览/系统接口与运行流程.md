# 系统接口与运行流程

## 硬件连接

- A 板：ADS1298 前端、HDMI 显示器、ST7789 TFT、GT911 触摸、板载按键/SW0。
- B 板：USB 摄像头；与 A 板用一根网线直连。
- 两板应独立稳定供电。历史调试中曾出现接地/供电导致的共模噪声，最终确认供电完整性对 ECG 质量至关重要。

## 典型启动顺序

1. A、B 板上电，systemd 服务加载各自位流和应用。
2. B 板启动相机与 TCP 8765 视觉服务。
3. A 板显示 PulseAtlas 首页并周期检查 ECG、USB/视觉服务和网络状态。
4. 进入实时监测：A 板启动 ADS1298 连续采集，PL 流水输出波形、质量与 QRS 数据。
5. 进入 AI 分析：从连续、质量合格的 10 秒 12 导联窗口执行 ECG 五分类。
6. 进入视觉贴片引导：A 板请求/接收 B 板的 JPEG 预览、关键点、电极 ROI 与识别状态。

## 板间协议

- B 板监听：TCP 8765。
- 帧格式：定长/长度前缀头部 + JSON 元数据 + JPEG 图像负载。
- JSON 包含相机、模型、推理耗时/FPS、关键点、电极候选、颜色/时序状态等字段。
- A 板将 B 板结果映射到 HDMI/TFT 视觉页面，同时保留 ECG 采集与 UI 主循环。
