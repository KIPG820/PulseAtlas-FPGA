# A 板技术说明

## PS/PL 分工

### PL

| IP | 核心职责 | 关键输出 |
|---|---|---|
| `ads1298_acquire_ip` | ADS1298 复位、启动、寄存器访问和连续 SPI 读帧 | 8 通道样本、帧序号、丢帧计数 |
| `ecg_quality_ip` | 导联脱落、饱和、平线和突跳检测 | 质量掩码/标志 |
| `ecg_classic_filter_ip` | 基线高通、50 Hz 陷波、FIR 低通、定点流水 | 滤波波形、各级控制 |
| `ecg_qrs_ip` | 类 Pan-Tompkins：带通、微分、平方/能量、移动积分、自适应阈值、不应期、多导联融合 | R 帧、RR、导联掩码、事件标志 |
| `ecg_wavelet_ip` | DWT 阈值去噪与重构、延迟对齐 | 小波去噪波形 |
| `ecg_lead12_ip` | 由 8 路采样重构标准 12 导联 | I、II、III、aVR、aVL、aVF、V1-V6 |
| `ecg_packet_ip` | 合并原始/12 导联/QRS 记录，32 位 AXI-Stream 打包 | DMA 数据流、TLAST、拥塞计数 |

12 导联重构关系：

- `I = II - III`
- `aVR = III/2 - II`
- `aVL = II/2 - III`
- `aVF = (II + III)/2`

### PS

- 通过 AXI-Lite 配置 7 个 IP，通过 DMA 接收结构化记录。
- 维护连续采集环形缓冲、质量门控、波形比例和滤波开关。
- 执行 ECG 模型的 PS NumPy 或 FPGA+DMA 路径，并各运行 3 次取平均用于公平对比。
- 生成首页、实时监测、12 导联、单导联放大、心率趋势、时频图、AI 分析、视觉、历史和设置页面。
- 驱动 HDMI，以及 ST7789 横屏 TFT；读取 GT911 触摸和板载按键/SW0。

## 12 导联 AI 输入门控

AI 输入要求连续 10 秒、12 导联、质量标志合格。采样链启动后先经历滤波稳定期，再从环形缓冲提取窗口；推理不应重启 ECG 采集链。该门控用于避免把脱落、饱和或明显缺口数据送入模型。
