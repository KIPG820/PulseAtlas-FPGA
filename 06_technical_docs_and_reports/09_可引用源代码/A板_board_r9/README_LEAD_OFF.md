# PulseAtlas R9 单引擎 AI 对照与 ECG 网格版（2026-10-04a）

本版本把 PS 和 FPGA 推理改为可选模式。一次点击只运行当前选中的引擎，各自连续推理 3 次并取平均；不会在同一次操作里同时占用 PS 和 FPGA。第一次运行会从正常 ECG 流取得一段合格的 10 秒输入并完成编码。切换到另一引擎后，第二次运行会复用完全相同的编码输入，因此两边输入一致。两边都完成后，再按一次“开始推理”会清除旧对照并取得新窗口。

计时口径：

- **PS NumPy**：计入 ARM 上 run_codes() 的完整参考推理。
- **FPGA + DMA**：计入输入打包、PYNQ DMA 缓冲区分配、数据复制与 flush、DMA 传输、PL 推理完成等待、输出读取、DMA idle 等待和缓冲区释放。
- 两边共用的 ECG 采集、稳定窗口等待与输入编码不计入任一方的推理时间；页面显示各自 3 次平均值及平均时间之比。

推理输入仍需经过 3,000 帧滤波稳定期，模型始终使用连续、质量标记全零的 10,000 帧。程序保留最多 10 秒回看，在最近约 20 秒稳定采集中选择最新的合格窗口；短暂质量异常不会让整次点击只能盯着最新窗口等待，但任何真实帧缺口或质量标记都不会被补帧或放行。若找不到合格窗口，界面分别报告最新窗口问题和本次新增 ADC 掉帧数，避免把累计计数误当成本次掉帧。每个引擎的三次推理完成后会复核电极接触；探测期间的重启帧不会进入模型输入。如果接触复核失败，当前缓存输入、两边计时及分类结果都会清除。接触复核会短暂重启实时 ECG 采集，这是 R9 固件运行时切换 ADS1298 LOFF 模式的现有限制。

12 导联页选中任一导联放大后，网格由波形图表自身绘制。每次实时数据更新都会同时重画完整心电纸网格和波形，避免局部刷新后网格消失。

## 上板

将整个 ZIP 上传到板端 Jupyter 文件页。在板端终端找到 ZIP：

    find /home/xilinx -maxdepth 3 -name 'PulseAtlas_R9_LVGL_HDMI_UI_20261003_ecgfix8.zip' -print

把下面第一行换成找到的 ZIP 完整路径，然后解压到新目录：

    ZIP='/home/xilinx/jupyter_notebooks/PulseAtlas_R9_LVGL_HDMI_UI_20261003_ecgfix8.zip'
    mkdir -p /home/xilinx/pulseatlas_r9_ecgfix8
    unzip -oq "$ZIP" -d /home/xilinx/pulseatlas_r9_ecgfix8
    cd /home/xilinx/pulseatlas_r9_ecgfix8
    sha256sum -c SHA256SUMS.txt
    sudo -E /usr/local/share/pynq-venv/bin/python run_pulseatlas_r9.py

启动日志应出现 `PulseAtlas R9 ECG paper-grid redraw fix 2026-10-04a`。放大任一导联后观察网格，并等待波形刷新；网格应持续覆盖在图表背景中。先在“实时监测”页按 BTN2 开始采集，等待超过 13 秒，再进入“AI 分析”页：

- BTN0 选择 **PS NumPy**。
- BTN1 选择 **FPGA + DMA**。
- BTN2 只运行当前选择的引擎。
- BTN3 返回首页。

屏幕上的两个模式按钮也可触控选择。先选一个引擎运行；完成并通过电极复核后，再切换另一引擎运行，状态会提示复用同一段 10 秒输入。只有当两边均完成后，再次按 BTN2 才会开始新的输入窗口。推理期间模式选择不会改变当前正在运行的引擎。

## 建议验证

1. 选择 PS，运行一次：进度条应推进到完成，FPGA 计时仍为 --。
2. 切换 FPGA + DMA，运行一次：PS 不会再次运行；界面保留上一步 PS 均值并显示 FPGA 均值与加速比。
3. 核对第二次运行状态为“复用同一段 10 秒心电”，代表性片段保持同一波形。若两种推理的量化输出不同，界面会给出不一致提示。
4. 两边比较后再按一次开始，确认旧计时清除并开始收集新的稳定窗口。
5. 若电极检测失败，确认分类和计时均清除；不要把失败的对照结果用于性能结论。

每次所选后端仍会以同一段输入重复运行并以均值计时；三次校验仅用于计算稳定的平均耗时，显示层不暴露循环次数。

该界面仅供工程验证，不作临床诊断。R9 当前的 LOFF 探测可核验配置中的输入电极脱落状态，但 RL 是右腿驱动输出，不能独立确认其贴合情况。
