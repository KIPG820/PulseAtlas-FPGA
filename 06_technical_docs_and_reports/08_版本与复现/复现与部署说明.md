# 复现与部署说明

## A 板

- 运行目录核心：`ui/pulseatlas/board_r9`。
- 位流/硬件描述：`ecg_frontend.bit`、`ecg_frontend.hwh`。
- 入口与状态机：`pulseatlas_r9_app.py`。
- 硬件流水驱动：`ecg_full_pipeline.py`。
- TFT：`pulseatlas_tft_backend.py`、`pulseatlas_tft_render.py`。
- FPGA NN 驱动：`ecg_nn_driver.py`。

## B 板

- R16 bitstream + R19 非缓存同步优化后端。
- R20 叠加电极时序可靠性逻辑。
- TCP 服务监听 8765，A 板作为客户端。

## 报告复现建议

1. 先使用本包现成的资源、时序和 JSON 结果写报告，不重新跑完整 Vivado。
2. 如需复现实测，记录日期、位流版本、相机输入、模型输入尺寸、重复次数和是否包含 JPEG/网络。
3. ECG 数据集和大体积训练缓存未打包；按 `04_算法与模型/ECG模型/README.md` 下载 PTB-XL。
4. 开发仓库完整路径为 `D:\ECG-fpga`；本包只保留报告所需的精选源码和证据。
