# PulseAtlas 项目报告资料交接包

生成日期：2026-10-29

本包面向后续项目报告、答辩材料和演示说明的撰写者。它不是完整开发仓库，而是从工程中筛选出的“可核验材料”：系统说明、双板架构、PL/PS 分工、算法与模型、资源与时序报告、实测性能、界面图片、关键源码以及已知限制。

## 建议阅读顺序

1. `00_先看这里/事实与口径清单.md`：先确认哪些结果可直接写入报告。
2. `01_系统总览/项目总览.md`：了解整个系统和创新点。
3. `02_A板_ECG与交互/A板技术说明.md`：理解 7 个 ECG PL IP、PS 软件和显示交互。
4. `03_B板_视觉加速/B板技术说明.md`：理解 YOLO11n-pose、INT8 卷积核和电极 ROI 检测。
5. `05_测试与结果/实测结果汇总.md`：引用统一的资源、时序、精度和速度数据。
6. `06_UI与图片素材`：选取架构图、界面图和展示图片。
7. `08_版本与复现/文件索引.csv`：追溯每份材料的原始工程位置与 SHA-256。

## 推荐项目名称

**PulseAtlas：基于双 PYNQ-Z2 异构协同的多导联心电分析与视觉贴片引导系统**

较短标题可用：**双板协同心电智能分析系统**。

## 报告中的边界

- 系统属于科研/竞赛原型，输出仅作辅助参考，不构成临床诊断。
- B 板实测“相机采集帧率”“界面预览帧率”“模型推理 FPS”必须分别书写。
- 视觉演示回放属于演示基础设施，不能作为实时 FPGA 推理性能证据。
- VCG 三维图仅完成设计提案，未纳入最终工程。
- A 板滤波关闭归零问题已在本地定位并修补，但交接时未完成板端部署回归，见已知问题。
