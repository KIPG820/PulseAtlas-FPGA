# 作品简介与创新点

## 可供报告改写的作品简介

PulseAtlas 是一套基于双 PYNQ-Z2 异构协同架构的多导联心电分析与视觉贴片引导系统。A 板面向生物电信号链，在 FPGA PL 中集成 ADS1298 采集、信号质量检测、经典滤波、小波降噪、QRS 检测、十二导联重构和 AXI 数据打包等七类硬件 IP，并由 ARM PS 完成十秒心电窗管理、五分类 1D-ResNet 推理以及 HDMI/TFT 双屏交互。B 板作为视觉协处理节点，使用 256×192 的 YOLO11n-pose 姿态网络和 INT8 卷积加速核，在人体标定点附近生成十个电极候选区域，再通过轻量贴片存在模型、颜色特征和时序门控判断贴片状态。两板通过以太网传输结构化结果和 JPEG 预览，组成从电极放置引导、实时心电采集、信号处理到智能分析的完整原型闭环。

## 可重点展开的创新点

1. **双 Zynq 异构协同**：将实时 ECG 流水和视觉推理分布到两块 XC7Z020，避免单片 BRAM/DSP 资源冲突，并通过轻量网络协议统一显示。
2. **七 IP ECG 硬件链**：从 ADS1298 帧采集到 QRS、12 导联和 DMA 打包形成可配置、可旁路、可计数的 AXI 流水线。
3. **同一系统中的两种 FPGA 加速范式**：A 板侧重一维流式信号处理和 1D CNN，B 板侧重二维 INT8 卷积、连续缓冲区与 PS/PL 调度优化。
4. **位置约束的电极识别**：利用姿态/标定先验把通用检测问题转化为十个固定 ROI 的局部二分类，降低模型和板端开销。
5. **工程闭环与可验证性**：提供 HLS C 仿真、C/RTL 协同仿真、Vivado 实现、板端逐层一致性和真实服务 FPS 等多层证据。

## 一句话概括

用两块 PYNQ-Z2 将“视觉引导贴电极”和“硬件流水处理并分析十二导联心电”连接成一个可交互的完整系统。
