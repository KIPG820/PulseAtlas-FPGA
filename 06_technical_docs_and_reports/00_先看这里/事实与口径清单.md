## 必须写清的系统分工

- **A 板**负责 ADS1298 多通道采集、质量检测、经典滤波、小波降噪、QRS 检测、12 导联重构、数据打包/DMA、心电分类推理、HDMI/TFT 交互和与 B 板通信。
- **B 板**负责 USB 摄像头采集、YOLO11n-pose 姿态模型、INT8 卷积 PL 加速、PS 后处理、人体标定点到十个电极 ROI 的投影、电极存在性/颜色与时序判定，并通过以太网把 JPEG 和 JSON 元数据发给 A 板。
- 两板通过直连以太网协作，B 板服务使用 TCP 8765，消息为长度前缀 JSON 头加 JPEG 负载。

## 不能混用的指标

- 相机约 13 FPS ≠ 姿态模型约 1.65 FPS。
- 预览刷新率 ≠ 神经网络真实推理 FPS。
- PC 端离线视频回放 ≠ B 板实时 FPGA 推理。
- PTB-XL 公共数据集指标 ≠ 临床现场诊断准确率。
- 电极局部模型 holdout 指标来自同一人/同一采集家族，不能外推为跨人群泛化性能。
