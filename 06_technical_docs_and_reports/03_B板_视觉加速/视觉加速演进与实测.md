# 视觉加速演进与实测

| 版本 | 主要改动 | 同输入/板端结果 |
|---|---|---|
| R14 | 90.909 MHz 收敛版本 | R7 0.536142 s → R14 0.456947 s，提升 17.33%；实时约 1.469 FPS |
| R15 | 47 层选择性零拷贝、缓冲复用 | 图执行 0.453070 s → 0.424104 s，提升 6.83%；实时约 1.58–1.61 FPS |
| R16 | depthwise 专用路径，196 DSP | 96 中间输出与 3 最终输出保持一致；时序收敛 |
| R19 | 移除非缓存 BO 冗余 sync | 9 次均值：R15 0.4080 s → 0.3732 s；实时 1.657–1.660 FPS |
| R20 | 电极 2-of-3 时序门控与颜色稳定判定 | 相机约 13 FPS，姿态约 1.65 FPS，无服务错误 |

## 性能瓶颈

R19 的纯图执行仍约 0.3732 s，其中 PL 核约 0.184 s。即使不计摄像头、JPEG 和电极判定，图执行上限约 2.68 FPS。剩余时间主要来自多次 PS↔PL 调用、图算子在 PS 上执行以及中间特征图写回 DDR。

## 合理后续方向

1. 在单次 PL 调用中融合连续量化算子。
2. 对连续卷积采用 AXI-Stream/HLS dataflow 和行缓冲，减少中间层落 DDR。
3. 若 XC7Z020 资源不闭合，训练更小的 QAT 姿态模型，并以本项目贴片定位数据评估，而不是只比较通用关键点 mAP。

当前报告不得把 5 FPS 写成已实现结果。
