# B 板固定位置电极存在性模型候选版

这个候选版只回答固定标定点附近“看到了贴片 / 没看到贴片”。它不识别 RA、LA、V1-V6，不判断电极是否与皮肤接触，也不验证电气连接。人体姿态模型、关键点标定、固定 ROI 搜索、FPGA 位流和 A 板程序均未改动。

## 模型接口

- 文件：`tiny_patch_presence_batch10.onnx`
- 输入：固定批次 `[10, 3, 96, 96]`，RGB、float32、像素值归一化到 `[0,1]`
- 输出：`[10, 2]` logits，顺序为 `pad, none`
- 结构与 R3 相同：24,842 参数，约 101 KB；可直接替换同名 R3 模型文件进行测试
- 本地 OpenCV DNN 4.12 与 PyTorch 输出最大绝对误差为 `4.77e-7`

## 数据与验证

用户手工标注的 259 张、10 类共 1,046 个贴片框全部合并成一个正类。按原始视频组拆分，训练 182 帧、验证 45 帧、留出测试 32 帧；相邻视频帧不会跨集合。负类由同图的躯干局部空区域生成，并排除所有标注贴片框，另用宽松肤色筛选减少背景负例。

在同一批合成局部 ROI 上、均使用 0.5 pad 概率阈值：

| 集合 | 当前 R3 | 新候选 | 新候选贴片召回 | 新候选无贴片召回 | 无贴片误报率 |
|---|---:|---:|---:|---:|---:|
| 验证，180 个 crop | 73.9% | 88.9% | 82.2% | 95.6% | 4.4% |
| 留出测试，126 个 crop | 75.4% | 92.1% | 91.9% | 92.2% | 7.8% |

验证集上将阈值改为 0.6 时，平衡准确率仍为 88.9%，贴片召回为 80.0%，无贴片误报率降至 2.2%。本候选模型仍按原运行逻辑使用 0.5；是否提高阈值应结合板上画面再决定。

## 限制

这 259 张图来自同一人、同一轮拍摄，且没有单独录制的完全无贴片画面；所以无贴片 crop 是根据未标注躯干区域合成的伪负例，仍可能有未标出的贴片混入。指标反映这些视频里的局部裁剪分类，不证明新姿势关键点一定落在电极中心，也不能代表不同人、光线和摄像头下的效果。先作为 B 板测试候选，不覆盖 R3 原版。
