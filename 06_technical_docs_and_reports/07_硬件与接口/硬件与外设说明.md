# 硬件与外设说明

## 核心平台

- 两块 PYNQ-Z2，SoC 为 XC7Z020CLG400-1。
- A 板作为心电、交互与显示主机；B 板作为视觉协处理节点。

## ECG 前端

- ADS1298 8 通道模拟前端，经 SPI 接入 A 板 PL。
- 8 个物理通道与肢体/胸导联结合，经 PL 重构为 12 导联。
- 原理图收录于 `原理图与规范/SCH_Schematic1_2026-09-14.pdf`。
- 实际调试证明稳定供电、模拟/数字地连接和 RLD 回路对共模噪声非常敏感。

## 显示与触摸

- HDMI：A 板主显示输出。
- TFT：ST7789，横屏显示；实际接口按 SPI 时序驱动。
- 触摸：GT911，I²C 访问；屏幕与触摸控制器不是同一种总线协议。
- UI 采用局部更新、帧缓存与模式切换降低 TFT 刷新负担。

## 网络

- A/B 直连以太网。
- B 板视觉服务 TCP 8765。
- 传输 JPEG 预览和 JSON 元数据，不传原始神经网络中间特征图，因此带宽相对可控。
