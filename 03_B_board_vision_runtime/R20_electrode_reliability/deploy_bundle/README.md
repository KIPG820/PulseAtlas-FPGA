# PulseAtlas B R20 电极识别可靠性候选

此包对应已部署到 B 板的三个改动文件，以及运行时依赖的两份未改动颜色特征代码。

## 行为变化

- 电极候选需在最近 3 次新鲜推理里至少出现 2 次，才映射为绿色“已识别”；单帧候选显示为待确认，不再立即报绿。
- 颜色不匹配需在最近 3 次结果里至少 2 次稳定识别为同一颜色组，才提示颜色不匹配。
- 运行时检测间隔约 1 秒，历史超过 2.5 秒会清空，缺失标定点也会清空对应历史。
- 主电极存在模型权重没有更换。光照增强微调版虽然改善了模拟暗光，但白平衡表现不一致，因此没有部署。
- 颜色组模型只用训练视频及其合成曝光/白平衡样本拟合。验证、测试中的合成光照结果不能代替真实相机采集。

## 离线证据

- 原颜色模型按视频分组交叉验证：528 个训练电极框、17 个视频组，准确率 96.97%，最差组 72.73%。
- 增强候选：原光照准确率 96.59%，最差组 76.19%；模拟暗光、暖白平衡、冷白平衡、暗暖组合的训练视频留组准确率分别为 92.23%、94.89%、91.86%、93.94%。
- 独立 val/test 也是同一采集人/采集家族；其中 test 只含红、绿两组。必须用真实相机和其他光线再确认。
- 时序门控边界测试 5 项通过；含 UI 映射的端到端候选测试 1 项通过；PYNQ Python 中模型格式、OpenCV/NumPy 导入及两帧确认检查通过。
